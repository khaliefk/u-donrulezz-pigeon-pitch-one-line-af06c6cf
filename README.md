## What it does

`main.py` (Python 3, stdlib only) writes one line to `/output/entry.txt`: the
elevator pitch a city pigeon gives investors for its startup. No network, no
input files, no dependencies.

## The pitch

> I'm raising seed funding, literally seeds, for an app that tells pigeons where crumbs drop before the seagulls do. Revenue model: crumbs. We're already profitable.

## Run

```sh
python3 main.py
```
